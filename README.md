# DeoDent — зеркало боевого сайта

Точная копия (byte-for-byte) сайта **https://deodent.vercel.app**, снятая 25.11.2026.

## Откуда взялось
- Боевой сайт деплоился через `vercel deploy` (source = `cli`) из локальной папки, в GitHub-репозитории `wolfpauk/Deo-Dent` коммитов нет (пусто), sourcemap'ы на сайте отключены.
- Поэтому источник восстановлен зеркалированием продакшена: index.html идентичен (sha256 `2949f8d2…`), рядом лежат все ресурсы, на которые он ссылается.
